Immanuel Löw, Die Flora der Juden

Vienna and Leipzig, 1924–34, four volumes in five: the standard reference on plants in Jewish literature, in German, with Hebrew, Aramaic, Syriac, Arabic and Greek on every page. This is a test reading edition: machine transcription and English translation of a few pages, made to see what current tools can do.

What this is, and what it is not

  • The transcription and the translation are machine output (Claude Opus 5.5). One page (Bd. I p. 194) was checked by hand; its Syriac words are not yet verified.
  • Abbreviations are expanded from Löw's own list in Bd. IV pp. 731–740 where possible (table).
  • Each page links to the scan: please check it before citing anything.
  • Code, data, method and costs: github.com/EzraBrand/low-flora.
